# Temperature Converter

A simple web version of the Temperature Converter project.

## Supported conversions
- Celsius ↔ Fahrenheit
- Celsius ↔ Kelvin
- Fahrenheit ↔ Kelvin

## GitHub Pages
Upload `index.html`, `style.css`, and `script.js` to the root of the repository, then enable GitHub Pages from **Settings → Pages** and select **Deploy from a branch → main → /(root)**.

The original Java source can remain in the repository as `TemperatureConverter.java`.
